Releases

A short summary of each SenHub Agent release. The full release note, with every change and the upgrade steps, is in the documentation.

0.7.1
2026-11-12

OpAMP remote management and parallel probes

0.7.0 was not released: 0.7.1 replaces it, with one more fix to the masking of the configuration shown and sent to a management server. The agent can be managed remotely through OpAMP Enterprise with signed overlays. Probes start in parallel and each accepts a collect_timeout. PRTG and Nagios first readings wait for initial data.

Before you upgrade

  • Linux process probe no longer reports kernel threads unless include_kernel_threads: true is set.
  • config show --redact and remote management mask more values, including any parameter whose name contains pass, token, key, cookie, dsn, or uri.
  • Network interface oper_state now uses the seven RFC 2863 snake_case values and administrative state moves to admin_state.
  • Keep host:port for OTLP outputs while a rollback to 0.6.5 or earlier is possible.

0.6.5
2026-10-29

Secrets masked in log records

Every log record now passes through a masking step before it leaves the agent, so passwords and tokens in clear do not reach the backend. The Proxmox VE probe reads disk, ZFS, and backup health. The console gains a page per probe.

Before you upgrade

  • Secrets are masked in log records by default; logs.redact.preset: false turns off built-in rules and log_redact: false leaves one probe unmasked.
  • config check warns on keys nothing reads, so a configuration that exited 0 may now exit 1.
  • PRTG sensors lose the Check Result channel by default; set prtg.check_result_channel: true to keep it.
  • filetail sends a multiline record after 5 seconds of quiet; adjust multiline.flush_timeout if a writer pauses longer.

Full release note

0.6.4
2026-10-18

SNMP discovery and Kubernetes from the node

The agent draws the network it sits on: routing tables, SNMP discovery over LLDP, and machines found along the way. Each Kubernetes node reports its kubelet metrics and pod logs. The series that say whether a service is running are renamed.

Before you upgrade

  • host.service.running replaces systemd.unit.active_state and windows.service.state; alerts on old names return nothing.
  • With no list configured, systemd and winservices watch only what the supervisor starts by itself: enabled units and automatic services.
  • Both probes are added by default as probes.d/05-services.yaml; rename to *.disabled to opt out.
  • SNMP topology is swept every minute instead of every ten minutes; devices no longer carry mgmt.ip.

0.6.2
2026-10-08

Fleet deployment and Linux packages

Signed Linux packages and repositories, with Ansible, Helm, and Podman Quadlet for large deployments. Probes can be declared from environment variables. The agent log masks a credential embedded in a probe's connection URI.

Before you upgrade

  • A host.name override that only reached metrics and logs now also names the host entity and its systemd units; host.id is unchanged.

Full release note

0.6.1
2026-09-30

Metric names and units follow the conventions

A corrective release that renames series after promtool check metrics flagged 0.6.0. Durations are now in seconds and throughputs in bytes per second. Dashboards and alerts on old names need updating; the full note includes the table.

Before you upgrade

  • Durations are in seconds and throughputs in bytes per second; a list of gauges loses its .total suffix.
  • Zabbix item keys follow the metric names; re-run zabbix setup to refresh templates.
  • A senhub-agent update run by 0.6.0 installs the binary without restarting; run sudo systemctl restart senhub-agent.

Full release note

0.6.0
2026-09-29

Native Zabbix and a separate administration key

The largest release so far. It adds native Zabbix support in both directions, a separate administration key for the console, and entities by default in the container. Read the upgrade list before installing.

Before you upgrade

  • The console and configuration API no longer answer to the agent key; use senhub-agent console to open it.
  • service.instance.id becomes a UUID and changes once, so series keyed on it restart.
  • An unfiltered process probe keeps only its per-name roll-up.
  • ActiveMQ and Redfish metrics are renamed, and SNMP interface series move to network_interface_name.

0.5.5
2026-09-16

Web console and official container image

A rebuilt web console with a Probes page and Settings page, self-signed TLS by default, and an official container image at ghcr.io/senhub-io/senhub-agent. Operational fixes include config check reading values and uninstall cleanup.

Before you upgrade

  • Three changes to tag and channel names can break an existing configuration; the full note lists them.

0.5.4
2026-08-18

Per-container network counters

Container networking counters are read from the container's own network namespace, and containers include restart count, names, images, labels, and state.

Before you upgrade

  • The service unit now marks /var/lib/senhub-agent non-executable; the unit and binary move together.

0.5.3

OTLP logs and traces receiver

The OTLP receiver now accepts logs and traces, not just metrics, with a signals list to choose. The licence moves to its own license.jwt file next to agent.yaml. A free OS Updates probe reports pending updates and whether a reboot is required.

  • The licence now lives in its own file, license.jwt, next to agent.yaml.
