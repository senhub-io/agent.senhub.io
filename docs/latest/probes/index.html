    Probes¶

    Each probe targets one class of system and turns its state into typed metrics and log streams. Enable the probes you need — they share the same naming and tagging conventions across every output sink.

    CPU Free Per-mode utilization, per-core breakdown, load average Memory Free Physical memory, swap, Windows paging rates Network Free Per-interface throughput, packet and error rates Logical Disk Free Filesystem capacity, inode usage Linux Logs Free Systemd journal subscription → OTLP logs Windows Event Log Free Event Log channels with level/EventID filtering Process Monitor Free Per-process CPU, memory, threads, file descriptors Systemd Units Free Active/sub/load state and restart counter per unit Windows Services Free Service running/stopped state via SCM Chrony (NTP) Free NTP sync health: offset, frequency, skew, stratum OS Updates Free Pending updates, security updates, reboot required S.M.A.R.T. Disk Health Free SATA/SAS and NVMe drive health via smartctl IPMI / BMC Sensors Free Temperatures, fan speeds, voltages from BMC NVIDIA GPU Free GPU utilization, memory, temperature, power WiFi Signal Free Wireless signal quality on Windows + Linux SNMP Poll Free SNMPv2c polling: MIB-2, IF-MIB, LLDP topology SNMP Trap Free Trap/inform receiver (v2c + v3) → OTLP logs ICMP Check Free Multi-target ping: reachability, RTT, packet loss HTTP Check Free HTTP(S) status, latency phases, TLS cert expiry TCP Dial Free Raw TCP connect latency to host:port DNS Latency Free Resolution latency per name, per resolver Modbus TCP Free Poll Modbus TCP Holding Registers on PLCs/sensors UniFi Free Ubiquiti controller: devices, APs, client counts, WAN Ping Gateway Pro Default gateway reachability and RTT Ping WebApp Pro Web application availability via ICMP MySQL / MariaDB Free Connections, InnoDB, replication, slow queries PostgreSQL Free Connections, replication, bloat, archiver, pg_stat_statements
